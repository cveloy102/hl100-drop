# Проверки DROP

Актуально: 14 октября 2026 года. Минимальные версии ОС — целевые ограничения сборки, а не заявление о проверке на каждом устройстве.

| Проверка | Результат |
| --- | --- |
| Rust | fmt, clippy с запретом warnings, 15 тестов Windows / 16 Unix |
| Докачка | Настоящий TCP: смещения, обрывы, перезапуск, пауза, отмена, коллизии, потерянный финальный ACK, старый протокол |
| Windows | Self-contained x64, Inno Setup, установка, ярлыки, открытие файла с выделением |
| Android | ARM64 / x86_64, релизная подпись, unit tests / lint; реальный Poco F7 / Android 16 |
| Windows ↔ Android | Пользователь подтвердил папку, паузу и продолжение в обе стороны на файле 256 МБ |
| Выход из обоих приложений | Пользователь подтвердил восстановление незавершённой передачи |
| Целостность | Полученные тестовые копии 256 МБ совпали по SHA-256 с оригиналом |
| Mac | Universal app + dylib, lipo / codesign, 16 Rust tests, Swift C ABI, реальные TCP-файлы и коллизии |
| Скриншоты Mac | Настоящие AppKit views с демонстрационными данными, сохранены CI |
| Обновление 1.1.0 → 1.1.1 | Релиз подготовлен; полный пользовательский сценарий установки из всех приложений ещё предстоит проверить |

Новая версия на физическом Mac и M1 Pro пока не подтверждена. Нет проверки всех сценариев на Windows 10 / Android 12 / macOS 12, каждой гостевой сети, облачных Android-провайдерах и переходе устройства в сон. macOS имеет ad hoc подпись, без Developer ID / нотариализации.

Скорость зависит от сети и накопителей. Loopback-замеры проверяют поток и байты, но не являются гарантией скорости Wi-Fi. Докачка не добавляет подтверждения на каждый блок.
