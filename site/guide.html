[ 01 / WINDOWS ]

Обычный установщик.

  1. Скачай EXE из последнего релиза и запусти установку. Права администратора не нужны.
  2. Открой HL100 Drop через «Пуск» или ярлык на рабочем столе.
  3. Задай имя и папку приёма, нажми «Начать».
  4. Если брандмауэр запросит доступ, разреши приложение в своей частной локальной сети.

Windows 10+ x64. .NET входит в установку. Закрытие окна оставляет DROP в трее; полный выход — через меню значка.

[ 02 / ANDROID ]

Установи. Выбери папку.

  1. Скачай APK из релиза, открой и подтверди системную установку.
  2. При необходимости разреши установку именно из этого источника в запросе Android.
  3. Открой DROP, задай имя и выбери локальную папку приёма.
  4. Подтверди системный доступ к папке, нажми «Начать».

Android 12+, ARM64 / x86_64. При обновлении устанавливай поверх прежней версии, не удаляя приложение.

[ 03 / MACOS ]

Один DMG для двух архитектур.

  1. Скачай универсальный DMG и открой образ.
  2. Перетащи HL100 Drop.app в «Программы» и запусти.
  3. Задай имя и папку приёма. DROP появится в строке меню.

macOS 12+, Intel и Apple Silicon без Rosetta. Подпись ad hoc, без нотариализации. Если запуск заблокирован, используй доступный системный вариант разрешения конкретного приложения в «Конфиденциальность и безопасность».

Настоящий AppKit с демонстрационными данными из CI.

[ 04 / TRANSFER ]

Устройство → файл.

Открой DROP на обоих устройствах в одной сети. Выбери получателя.

  • На Windows / Mac перетащи файл или папку на карточку устройства либо воспользуйся кнопкой отправки.
  • На Android «Отправить файлы» предлагает фото / видео, файлы и папку.
  • В галерее или другом приложении Android используй «Поделиться → DROP», затем выбери устройство.

Приём автоматический. Папка отображается одной строкой с общим размером; вложенная структура сохраняется. Совпадающее имя получает суффикс вместо перезаписи. Готовый объект на Windows / Mac можно нажать, чтобы выделить его в Проводнике / Finder.

[ 05 / KEEP GOING ]

Пауза — это пауза.

Нажми «Пауза» в активной передаче. «Продолжить» снимет ручную паузу. При обрыве связи DROP автоматически ждёт получателя и повторяет соединение; после выхода из обоих приложений незавершённая передача восстанавливается.

  • Докачка требует версии 1.1+ на обеих сторонах.
  • Оригинал должен оставаться доступным и неизменённым.
  • Ручная пауза сохраняется после перезапуска.
  • Готовые файлы папки не отправляются повторно; отмена оставляет завершённое и удаляет незавершённые части.
  • Не удаляй служебную .drop-state при незавершённых передачах.

Android: некоторые облачные / потоковые провайдеры не поддерживают позиционную запись, а временный доступ «Поделиться» может исчезнуть после выхода. Тогда источник нужно выбрать заново.

[ 06 / BACKGROUND ]

Когда приложение свернуто.

Windows работает в трее; автозапуск и уведомления включаются в настройках. Mac остаётся в строке меню.

На Android можно включить приём в фоне и его длительность. Для активной фоновой службы Android требует уведомление. Остановка службы прекращает фоновый приём; ограничения батареи производителя могут влиять на работу.

[ 07 / UPDATE ]

Проверь 1.1.0 → 1.1.1.

  1. Оставь на устройстве установленную 1.1.0.
  2. Настройки → «Проверить обновления». Должна появиться версия 1.1.1.
  3. Нажми «Обновиться» и дождись скачивания / проверки SHA-256.
  4. Windows: заверши работу установщика. Android: подтверди системное обновление APK. Mac: закрой DROP и замени приложение из DMG в «Программах».
  5. Открой DROP: версия новая, имя и папка сохранены. Проверь небольшой файл в обе стороны.

Обновление требует интернета. Предварительные релизы не показываются в стабильном канале. Не удаляй приложение перед установкой.

[ 08 / HELP ]

Если что-то пошло не так.

Не вижу устройство

Проверь одну сеть, включённый приём и открытый DROP. Гостевой Wi-Fi с изоляцией клиентов, VPN и брандмауэр могут блокировать обнаружение.

Не продолжается после перезапуска

Открой оба приложения, проверь доступ к оригиналу и папке приёма. Сними ручную паузу. Для временного URI Android может понадобиться новая отправка.

Нет кнопки паузы

Она появляется в активной карточке после согласования докачки. Старые версии получателя передают без этой возможности. После завершения кнопки скрыты.

Какая скорость должна быть?

Она зависит от Wi-Fi, накопителей и устройств. Конкретной скорости DROP не обещает; докачка не добавляет подтверждения на каждый блок.

DROP предназначен для доверенной LAN: нет шифрования / авторизации, приём автоматический.
