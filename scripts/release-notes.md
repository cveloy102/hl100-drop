DROP 0.1.4 — удобная отправка на Android и управляемая работа в фоне.

- Исправлена ошибка Address already in use (os error 98): изменение фоновых настроек не перезапускает ядро; остановка дожидается освобождения слушающего сокета, Unix TCP listener допускает повторный запуск после закрытой передачи.
- По умолчанию Android работает при открытом DROP, без постоянного уведомления.
- В настройках можно включить фоновый приём на 15, 30, 60 минут после сворачивания или без таймера. По истечении времени начавшиеся передачи завершаются, затем приём выключается.
- Уведомление появляется только при фоновом приёме или незавершённой передаче после сворачивания. Есть таймер и кнопка выключения фонового приёма.
- «Отправить файлы» предлагает «Фото и видео» либо «Файлы», используя системные окна Android.
- «Поделиться → DROP» открывает выбор устройства и поддерживает один или несколько файлов. Отправка текста и ссылок пока не поддерживается.
- Убраны кнопки «Выбрать папку» под устройствами Android и Windows. Папка сохранения остаётся в настройках; Windows по-прежнему принимает папки через drag-and-drop.

Подписанный APK установлен на Poco F7. Три unit-теста проверяют фоновый режим, таймер, завершение передачи и возврат в приложение. Android lint прошёл; Windows собран с установщиком. Протокол совместим с предыдущими версиями; ядро обновлено до 0.1.3.

Предварительный релиз устанавливается вручную: встроенные обновления получают стабильные релизы GitHub. Пользователь подтвердил отправку через «Поделиться», выбор фото/файлов, отсутствие постоянной плашки и включение/выключение фона без ошибки 98.
