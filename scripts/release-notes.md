HL100 Drop 0.1.0 — первая тестовая версия.

- Нативное приложение Windows 10+ с установщиком и приложенным .NET runtime.
- Нативное приложение Android 12+, ARM64 и x86_64.
- Обнаружение устройств, автоматический приём, файлы и папки, прогресс и отмена.
- Настройки имени и папки, обновления через GitHub Releases.
- macOS-приложение будет добавлено следующим этапом; ядро и инструкция интеграции уже в репозитории.

Докачка отсутствует. Перед стабильным релизом требуется проверка Windows ↔ Android на физических устройствах в одной локальной сети. Для приёма на Android приложение запускает службу с постоянным уведомлением. Закрытие окна Windows оставляет приложение в трее.
