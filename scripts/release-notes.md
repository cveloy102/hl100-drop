DROP 0.1.2 — тестовая версия Windows и Android.

- Исправлена остановка обнаружения устройств Android после Interrupted system call (os error 4): прерванный вызов повторяется, обнаружение восстанавливается после других ошибок.
- Windows: оформление DROP как на macOS, встроенные настройки, собственная верхняя панель и тонкая прокрутка.
- Windows: автозапуск в трее, один экземпляр приложения, уведомления о получении с отключением в настройках.
- Windows: подсветка получателя при перетаскивании файлов и папок.
- Имена и размеры файлов в истории Windows/Android. Нажатие полученного файла Windows открывает Проводник с выделением фактического файла, включая суффикс при совпадении имён.
- Android называется DROP; пакет, настройки и подпись сохранены.
- Включены исходники нативного приложения macOS и изменения общего ядра из macOS-ветки. Mac DMG в этот релиз не входит: обновлённое ядро нужно пересобрать на Mac.

Проверены реальные передачи Poco F7 ↔ Windows, повторное обнаружение по локальной сети, восемь тестов Rust, сборки Windows/Android, автозапуск и выбор файла в Проводнике. Установщик Windows включает .NET runtime. APK поддерживает Android 12+, ARM64 и x86_64.

Это предварительный релиз: встроенная проверка обновлений получает стабильные релизы GitHub. Для установки 0.1.2 скачайте установщик/APK ниже. Докачка отсутствует; проверки больших файлов, предельной скорости и минимальных ОС ещё предстоят.
