DROP 1.1.0 — пауза и возобновление передачи.

- «Пауза / Продолжить» на отправителе и получателе.
- После разрыва соединения передача автоматически продолжается с реально записанной позиции. Завершённые файлы папки не отправляются повторно.
- Незавершённые передачи и ручная пауза сохраняются после выхода из обоих приложений.
- Отмена удаляет частичные файлы и сохраняет завершённые; при выключенном получателе отмена доставляется после восстановления связи.
- Старые клиенты продолжают обмениваться файлами обычным способом. Для возобновления нужно обновить обе стороны.
- Поток данных остаётся несжатым TCP с буфером 1 МБ, без подтверждений на каждый блок и предварительного хеширования файлов.

Windows и Android проверены пользователем на файле 256 МБ, включая паузу и выход из обоих приложений. Автоматические TCP-тесты проверяют докачку после обрыва и перезапуска, ручную паузу, отмену, сохранение коллизий имён и старый протокол. Android требует доступный исходный URI и локальную папку с поддержкой позиционной записи. На Windows предлагается обычный установщик; исходники macOS содержат те же кнопки и новое ядро.
