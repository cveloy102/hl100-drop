DROP 0.1.3 — удобная отправка на Android и управляемая работа в фоне.

- По умолчанию Android работает при открытом DROP, без постоянного уведомления.
- В настройках можно включить фоновый приём на 15, 30, 60 минут после сворачивания или без таймера. По истечении времени начавшиеся передачи завершаются, затем приём выключается.
- Уведомление появляется только при фоновом приёме или незавершённой передаче после сворачивания. Есть таймер и кнопка выключения фонового приёма.
- «Отправить файлы» предлагает «Фото и видео» либо «Файлы», используя системные окна Android.
- «Поделиться → DROP» открывает выбор устройства и поддерживает один или несколько файлов. Отправка текста и ссылок пока не поддерживается.
- Убраны кнопки «Выбрать папку» под устройствами Android и Windows. Папка сохранения остаётся в настройках; Windows по-прежнему принимает папки через drag-and-drop.

Подписанный APK установлен на Poco F7. Три unit-теста проверяют фоновый режим, таймер, завершение передачи и возврат в приложение. Android lint прошёл; Windows собран с установщиком. Общий протокол и ядро 0.1.2 не менялись, совместимость с macOS сохранена.

Предварительный релиз устанавливается вручную: встроенные обновления получают стабильные релизы GitHub. Реальные сценарии «Поделиться», системного выбора фото и фонового приёма требуют проверки на телефоне.
