## DROP 1.2.0

DROP для Linux: новое нативное приложение на GTK 4.

### Linux
- Обнаружение устройств, отправка и автоматический приём файлов и папок, пауза и докачка, история передач — как на Windows, Mac и Android.
- Значок в трее, уведомления о полученных файлах с кнопкой «Показать в папке», автозапуск при входе. Закрытие окна оставляет приём работать.
- Перетаскивание на карточку устройства, «Открыть с помощью → DROP», пункт «Отправить» в Thunar и Dolphin.
- Три варианта установки:
  - `hl100-drop_1.2.0_amd64.deb` — Ubuntu 24.04+, Debian 13+, Kali, Linux Mint 22+: `sudo apt install ./hl100-drop_1.2.0_amd64.deb`. Пакет добавляет профили файрвола: `sudo ufw allow DROP`.
  - `HL100Drop-1.2.0-x86_64.flatpak` — любой дистрибутив с Flatpak, включая Ubuntu 22.04 и Debian 12: откройте файл в «Центре приложений» или `flatpak install --user HL100Drop-1.2.0-x86_64.flatpak`.
  - `HL100Drop-1.2.0-x86_64.AppImage` — без установки: `chmod +x`, затем запуск. Обновляется из приложения.

### Windows, Android и Mac
- Согласованный номер релиза, поведение без изменений.

### Обновление
Настройки → «Проверить обновления» → «Обновиться». Windows: установщик заменяет программу, настройки сохраняются. Android: подтвердите обновление APK. Mac: закройте DROP и замените приложение из DMG в «Программах». Linux AppImage заменяет себя сам; .deb и Flatpak — установите новый файл поверх.

В выпуске: установщик Windows 10+ x64, подписанный постоянным ключом Android 12+ APK, macOS 12+ universal DMG для Intel / Apple Silicon, Linux x86_64 (.deb, Flatpak, AppImage) и checksums.txt. macOS подписан ad hoc без нотариализации Apple. Файлообмен предназначен для доверенной локальной сети, без авторизации и шифрования.
