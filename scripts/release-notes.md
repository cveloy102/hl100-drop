HL100 Drop 0.1.1 — тестовая версия с исправлением приёма на Windows.

- Нативное приложение Windows 10+ с установщиком и приложенным .NET runtime.
- Нативное приложение Android 12+, ARM64 и x86_64.
- Обнаружение устройств, автоматический приём, файлы и папки, прогресс и отмена.
- Настройки имени и папки, обновления через GitHub Releases.
- macOS-приложение будет добавлено следующим этапом; ядро и инструкция интеграции уже в репозитории.

Проверена передача небольшого файла Windows → Poco F7 → Windows: SHA-256 совпадает, существующие файлы сохраняются. Исправлен режим TCP-сокетов Windows; добавлен тест с задержкой отправителя. Проверены установщик и удаление Windows, подпись APK и шесть тестов ядра.

Докачка отсутствует. Перед стабильным релизом остаются проверки больших файлов, скорости, минимальных версий ОС и полного сценария обновления. Для приёма на Android приложение запускает службу с постоянным уведомлением. Закрытие окна Windows оставляет приложение в трее. macOS-приложение пока не реализовано.
