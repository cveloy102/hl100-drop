DROP 1.0.1 — открытие файлов и отправка папок.

- Windows: нажатие на полученный файл открывает Проводник с выделением сохранённого файла, включая копии с изменённым именем. Отправленные файлы тоже открываются в исходной папке.
- Папка отображается одной строкой с общим размером, вместо списка всех вложенных файлов, в Windows, Android и исходниках macOS.
- Android: в меню отправки добавлен пункт «Папка» с системным выбором каталога.

Windows проверен передачей через native FFI и кликом в интерфейсе. Тесты ядра и статический анализ прошли, подписанный Android APK собран. Проверка нового выбора папки на физическом телефоне пока ожидается. Для обновления macOS нужно собрать новый DMG из исходников на Mac. Возобновление передач в этот релиз ещё не входит.
