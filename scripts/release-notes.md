## DROP 1.1.1

Файлы и папки между Windows, Android и Mac — напрямую в локальной сети.

### Что нового
- Контрастные кнопки «Пауза / Продолжить» и «Отменить» на Windows.
- Русскоязычная документация, инструкции и сайт продукта.
- Стабильный выпуск для проверки обновления из установленной версии 1.1.0.

### Входит в выпуск
- Windows 10+ x64: `HL100DropSetup-1.1.1.exe`, установка без прав администратора.
- Android 12+: `HL100Drop-1.1.1.apk`, постоянная подпись совместима с предыдущими релизными APK.
- macOS 12+: `HL100Drop-1.1.1-universal.dmg`, Intel и Apple Silicon в одном приложении.
- `checksums.txt`: SHA-256 всех установочных файлов.

### Обновление с 1.1.0
Откройте настройки DROP → «Проверить обновления» → «Обновиться».
Windows запускает установщик; Android запросит подтверждение установки APK; на Mac откроется DMG — закройте DROP и замените приложение в «Программах». Настройки сохраняются. Не удаляйте приложение перед обновлением.

### Пауза и докачка
Доступны на обеих сторонах. После обрыва связи передача продолжится с записанной позиции; ручная пауза и незавершённые передачи сохраняются после выхода из приложений. Для докачки обе стороны должны использовать 1.1 или новее; исходный файл должен оставаться доступным и неизменённым.

### Проверки и ограничения
Windows и Android: на реальных устройствах проверены файлы, папки, пауза и выход из обоих приложений. CI проверяет ядро, сборки всех платформ и Swift C ABI. Реальный запуск нового выпуска на пользовательском Mac ещё предстоит проверить. macOS имеет ad hoc подпись, без Developer ID и нотариализации Apple. Обмен не использует шифрование или авторизацию; предназначен для доверенной локальной сети. Android-провайдеры без позиционной записи и временные разрешения «Поделиться» могут ограничивать восстановление после перезапуска.
