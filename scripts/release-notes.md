## DROP 1.1.2

### Исправление Windows
- При входе в Windows настроенный DROP запускается сразу в трей, без пустого чёрного окна.
- Приём и обнаружение запускаются независимо от открытия окна. Повторный запуск вручную открывает уже работающий экземпляр.
- Установщик сохраняет выбор автозапуска и исправляет старую запись, которая могла указывать на временную / переносимую сборку.

Android и Mac получили тот же номер релиза; их поведение в этом выпуске не изменено.

### Обновление
Настройки → «Проверить обновления» → «Обновиться». Windows: установщик заменяет программу, настройки сохраняются. Android: подтвердите обновление APK. Mac: закройте DROP и замените приложение из DMG в «Программах».

В выпуске: установщик Windows 10+ x64, подписанный постоянным ключом Android 12+ APK, macOS 12+ universal DMG для Intel / Apple Silicon и checksums.txt. macOS подписан ad hoc без нотариализации Apple. Файлообмен предназначен для доверенной локальной сети, без авторизации и шифрования.
