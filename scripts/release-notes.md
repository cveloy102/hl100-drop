## DROP 1.1.3

Выпуск стабильности по итогам аудита всех трёх приложений.

### Все платформы
- Удалённый полученный файл больше не «занимает» имя: повторный приём сохраняется под исходным именем, а не как `имя (1)`.
- Служебный журнал докачки очищается после передачи и не растёт; приём папок из тысяч файлов больше не перезаписывает журнал на каждый файл.
- Устройства снова находят друг друга после переподключения Wi-Fi, сна и запуска до подключения к сети — без перезапуска DROP.
- Передачи с ошибкой больше не возвращаются в список после перезапуска.
- Ожидание недоступного получателя не мешает изменить настройки, обновиться или выйти.
- Ссылки, недоступные файлы и `.DS_Store` внутри папки пропускаются с сообщением, а не отменяют всю отправку.

### Windows
- Принимаются файлы с Mac и Android с символами `? | < > " *` в имени: такие символы заменяются на `_`.
- Новые имя и папка сохраняются только после успешного перезапуска приёма; выход больше не подвешивает окно.

### Android
- «Поделиться» работает из Telegram, WhatsApp и файловых менеджеров.
- Выбор файлов и фото, разделённый экран больше не выключают приём.
- Быстрее подготовка папок к отправке и приём папок с большим числом файлов.

### Обновление
Настройки → «Проверить обновления» → «Обновиться». Windows: установщик заменяет программу, настройки сохраняются. Android: подтвердите обновление APK. Mac: закройте DROP и замените приложение из DMG в «Программах».

В выпуске: установщик Windows 10+ x64, подписанный постоянным ключом Android 12+ APK, macOS 12+ universal DMG для Intel / Apple Silicon и checksums.txt. macOS подписан ad hoc без нотариализации Apple. Файлообмен предназначен для доверенной локальной сети, без авторизации и шифрования.
