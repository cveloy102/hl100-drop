# Участие в проекте

Для ошибки откройте [issue](https://github.com/cveloy102/hl100-drop/issues/new/choose): версии DROP / ОС, обе платформы, шаги, ожидаемое и фактическое поведение. Не прикладывайте личные файлы, ключи подписи и полный журнал с личными путями.

Для изменений сначала обозначьте сценарий. Инструкции сборки — в [DEVELOPMENT](docs/DEVELOPMENT.md). Сохраняйте совместимость протокола, реальные тесты передачи и общий визуальный язык DROP. Изменения хранения и докачки проверяйте на обрыве, перезапуске, коллизиях имён и отмене.
